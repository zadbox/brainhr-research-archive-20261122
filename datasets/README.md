# Données présentes dans cette archive privée

Le corpus de l’étude combine 6 000 exemples synthétiques et 1 074 exemples dérivés de textes de CV réels. Cet archivage GitHub contient les 6 000 exemples dont les champs sources indiquent explicitement `fictif: true` et `source_kind: synthetic`. Le manifeste conserve les décomptes par partition et les empreintes des fichiers.

Les 1 074 exemples dérivés de CV réels, les textes réels et les citations brutes des annotations restent hors de ce transfert. Les références aux dépôts privés existants figurent dans le README général. Ce dépôt privé d’auteurs ne constitue pas une nouvelle publication publique du corpus.

Le compagnon de 15 paires est un échantillon illustratif distinct. Les jugements A/B sans texte figurent dans `../annotations/` ; ils ne constituent pas une validation humaine indépendante.
