# Copies de fichiers sources

Ces dossiers conservent les fichiers de code suivis dans les copies locales des dépôts, avec leurs empreintes et le HEAD local dans `SNAPSHOT_MANIFEST.json`. Les données, fixtures, sorties, secrets potentiels et environnements installés sont exclus. Ce sont des snapshots de fichiers, pas des clones complets avec historique ni une nouvelle validation d’exécution. Les autres fichiers restent référencés par leur chemin exact dans l’inventaire général.
